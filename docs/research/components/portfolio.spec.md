# Portfolio Specification

- Target: `src/components/portfolio-section.tsx`
- Model: hover-driven project image cards.
- Light/ivory page rhythm. One full-width featured project and two equal supporting projects.
- Images retain original color; metadata stays outside images. Radius 14-16px.
- Hover: image scale 1.025 over 700ms; arrow moves 3px diagonally; no 3D tilt or neon.
- Mobile: all projects stack, image ratios preserved, metadata remains readable.
