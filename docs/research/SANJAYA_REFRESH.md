# Sanjaya-Inspired Homepage Refresh

## Constraint

The live reference is blocked by the browser environment. This is an interpretation of the requested direction, not a pixel-perfect clone. Existing HAMMAD.STUDIO content, imagery, pricing, routes, and contact flows remain the source of truth.

## Visual Direction

- Editorial composition with oversized typography and deliberate asymmetry.
- Warm paper surfaces contrasted with an ink-black project stage.
- Instrument Serif for expressive italic phrases; Geist for functional text.
- Large project imagery with layered depth instead of small dashboard cards.
- Fine rules, compact mono labels, restrained corners, and a muted acid accent.

## Interaction Model

- Navigation: scroll-responsive floating dock and animated mobile menu.
- Hero: load-in typography, pointer-responsive project stage, and scroll-linked depth.
- About: viewport reveal and a horizontal capability ticker.
- Services: hover/focus-driven active row with animated copy and image preview.
- Work: viewport image reveals, slow hover zoom, and directional arrow motion.
- Pricing and CTA: viewport reveals and strong hover states.

## Responsive Behavior

- Desktop: asymmetric 12-column layouts, oversized headline, layered showcase.
- Tablet: reduced overlaps and two-column service/work layouts.
- Mobile: single-column flow, no pointer parallax, compact navigation, scrolling ticker.

## Accessibility And Performance

- Motion respects `prefers-reduced-motion`.
- Decorative layers are hidden from assistive technology.
- Existing `next/image` optimization and responsive `sizes` are retained.
- Client boundaries are limited to interactive components.
